# Screenshot Postman — DUMMY / SIMULASI

Folder ini berisi 34 gambar mockup bergaya Postman berdasarkan request dalam koleksi proyek.

**PENTING:** Semua gambar diberi watermark "DUMMY / SIMULASI — BUKAN HASIL EKSEKUSI POSTMAN".
Kode status dan JSON response hanya contoh visual. Tidak ada request yang dijalankan ke localhost maupun hosting.
Gambar ini tidak boleh dipakai sebagai bukti bahwa API benar-benar lulus pengujian.

## Pembagian
- `screenshots/admin/` — request terkait admin, dashboard, fasilitas, review, profil, dan autentikasi admin.
- `screenshots/user/` — request terkait akun pengguna dan profil.
- `screenshots/public/` — endpoint publik seperti wisata, kategori, dan lokasi.

## Koleksi
Impor `Backend/api/postman/Perawat_Periwit.postman_collection.json` ke Postman untuk menjalankan pengujian asli.
Base URL koleksi dapat disesuaikan ke `http://localhost` atau URL hosting.

Jumlah request dalam koleksi: 34.

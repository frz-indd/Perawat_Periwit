# Explore Majaku — Skeleton UI

Skeleton ini dibuat berdasarkan 12 screenshot yang diberikan.

## Halaman
- index.html — Landing/Beranda
- auth/login.html — Login
- auth/register.html — Register
- pages/tentang.html — Tentang Kami
- pages/kategori-sejarah-budaya.html
- pages/kategori-buatan-kuliner.html
- pages/kategori-air-curug.html
- pages/kategori-alam.html
- pages/hasil-pencarian.html
- pages/profil.html
- pages/detail-wisata.html

## Catatan
- Bagian `IMAGE`, `HERO IMAGE`, `MAP / GOOGLE MAPS`, dan avatar adalah placeholder skeleton.
- Ganti placeholder dengan asset gambar asli project.
- CSS utama ada di `css/style.css`.
- CSS login/register ada di `css/auth.css`.
- Semua halaman menggunakan Bootstrap 5.3.3 melalui CDN.
